# Endre kontonummer

| Element | Tekst |
|---|---|
| Tittel | Endre kontonummer |
| Ingress | Utbetalingene fra Fjellkraft går til dette kontoet. Det nye kontonummeret gjelder fra neste utbetaling. Utbetalinger vi allerede har sendt, går til det gamle kontoet. |
| Feltnavn | Nytt kontonummer (11 siffer) |
| Hjelpetekst | Du godkjenner endringen med BankID i neste steg. |
| Feilmelding: tomt felt | Nytt kontonummer må fylles ut. |
| Feilmelding: feil antall siffer | Nytt kontonummer må ha 11 siffer. |
| Knapp | Godkjenn med BankID |
| Bekreftelse, tittel | Kontonummeret er endret |
| Bekreftelse, tekst | Fra neste utbetaling går pengene til konto {nytt kontonummer}. Vi har sendt deg en e-post om endringen. |
